What you get

  • One config for every emulator

    Batocera's configgen builds each emulator's settings at launch, per system or per game.

  • Display options

    Resolution, shaders, bezels and a performance overlay without editing config files.

  • Controls and hotkeys

    Map your pads once and use the same hotkeys in every emulator.

  • Your own session

    Run Retrobox from your desktop and come back to it with one shortcut.

  • Themes included

    EmulationStation themes give every system its own look out of the box.

  • Open source

    Read it, fork it, send a patch. Everything lives in retrobox-core.

Install

One command installs the latest release. It picks the right packages for your system.

curl -fsSL https://retroboxproject.github.io/install.sh | bash
  • Debian, Ubuntu and Fedora (and derivatives): installs .deb or .rpm packages with all their dependencies.
  • Ubuntu releases that are not LTS use the packages of the previous LTS.
  • Any other system (Arch, immutable distros, Bazzite...): builds from source. Add --source to force this on any system.

Read the installer script before running it if you prefer. The uninstall steps are in the README.
